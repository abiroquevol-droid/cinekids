# CineKids Web v3

Página/PWA para mostrar videos accesibles desde Google Drive mediante OAuth de solo lectura.

## Antes de publicar
1. Abre `config.js`.
2. Sustituye `PON_AQUI_TU_CLIENT_ID_WEB.apps.googleusercontent.com` por tu Client ID OAuth 2.0 de tipo **Aplicación web**.
3. Sube **todos los archivos** de esta carpeta a la raíz del repositorio `cinekids`.
4. Activa GitHub Pages desde Settings > Pages.

El permiso solicitado es:
`https://www.googleapis.com/auth/drive.readonly`

CineKids no guarda la contraseña de Google.
